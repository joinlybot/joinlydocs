JOINLY DOCUMENTATION SITE

Deploy this folder as a separate Vercel project for docs.joinly-bot.xyz.
Add docs.joinly-bot.xyz under Project Settings > Domains.
The root index.html is the documentation landing page; feature pages use /variables, /backups, /analytics, etc.
style.css is the CSS supplied with the original files.
vercel.json enables clean URLs without .html or trailing slashes.
